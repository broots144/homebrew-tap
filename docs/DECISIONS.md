## D-001 (2026-06-10): cask token is `claudeglance`

The app was rebranded from claude-usage-systray to ClaudeGlance. The old cask was removed rather than kept as an alias, since there were no outside users yet.

## D-002 (2026-09-27): the source repo's release job owns the cask

`Casks/claudeglance.rb` is generated by workshop144/claudeglance `release.yml` and pushed to `main` with a write deploy key scoped to this repo. The private key lives only as `HOMEBREW_TAP_DEPLOY_KEY` in the source repo, in a job with `permissions: {}` that shares no runner with the build. A missing key degrades to a warning, not a failed release. Consequence: hand edits to the cask are overwritten; change the template instead.

## D-003 (2026-11-06): no required checks on `main`

Because D-002 pushes directly to `main`, `main` only blocks force-push and deletion. The STATE guard runs on pull requests, not as a required check on pushes.
